// FEATURES

🗺️

Live agent tracking

Every Claude Code session under ~/.claude/projects/ appears as an NPC within seconds — no setup required.

🎭

Status-aware NPCs

Sprites react in real time: idle wandering when thinking, still with a pulsing ? when waiting for your approval.

📋

In-game approvals

Plan approvals and AskUserQuestion responses appear as RPG dialogue — answer with [Y] [N] or [1–4].

🎓

The Professor

An AI orchestrator that reads your map state and tells you what needs attention. Your fleet's second brain.

🖥️

Integrated terminals

Click any agent to open a real PTY terminal for that session — right inside the app, no context switch needed.

⌨️

Command palette

Press ⌘K to fuzzy-search every action and every running agent. Like VS Code, but for your Claude fleet.

🎮

Agent quick menu

Walk near any NPC, press Space — open conversation, view plan, ask a question, crack the whip with /fast, or kill the agent.

📊

Workspace insights

Local dashboard from your JSONL transcripts — sessions, tokens, top tools, plans accepted. Zero telemetry, everything stays on your machine.

✋

Drag & drop NPCs

Grab an agent on the map and drop it on a different house to re-home that Claude session. Or drag a project group from the palette onto a building.

🌍

English · Français · Español

Every label, dialogue line and dashboard chart translates instantly. Locale auto-detected on first run, persisted in your config.

⚙️

Tunable settings

Theme, sidebar width, language — saved to ~/.claude-workspace-map/config.json with live preview.

🔔

Desktop notifications

Get alerted when an agent is waiting for your answer, even when the app is in the background.

Desktop app

Download and open — the server starts automatically. No terminal needed.

macOS Apple Silicon .dmg arm64 macOS Intel .dmg x64 Linux .AppImage

From source

Runs in your browser or as an Electron window. Hot-reload included.

git clone https://github.com/guillaumeArgiles/\
  claude-workspace-map.git
cd claude-workspace-map
npm install
npm run dev

Then open http://localhost:5173

Requirements: Node.js 22+, Claude Code CLI installed and at least one active session running under ~/.claude/projects/. macOS or Linux.
